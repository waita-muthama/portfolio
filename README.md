## 🌐 Free 1-Click Deployment Options

### Method A: Netlify Drop (30 seconds)
1. Navigate to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop your `Portfolio` folder.
3. Your site is instantly published with a free custom URL and SSL certificate!

### Method B: GitHub Pages
1. Push this folder to your GitHub account: `https://github.com/waita-muthama/portfolio`
2. Under **Repository Settings &rarr; Pages**, choose branch `main` and folder `/ (root)` &rarr; Save.
3. Your site will be live at `https://waita-muthama.github.io/portfolio`.
